# Steve 0.3.2

- Choose serial or parallel preparation from measured component costs. Unknown and unsupported work stays serial; independent expensive components can build concurrently within the host budget.
- Return worker results without waiting for interpreter cleanup, retaining fresh-process isolation.
- Correct area reporting for tested curved and NURBS surfaces without changing model geometry or persistent face identities.
- Prevent the closing command palette from intercepting the next canvas click.
- Preserve an explicitly stopped build until the source changes or the user builds again.

The CAD audit remains open with 31 command entry points awaiting evidence. Linked-document and arbitrary Python component parallelism, center/inertia precision, construction-plane/reference editing and the reported clipboard case remain follow-up work. Integration falls back to a logged kernel area estimate when its reporting budget is exhausted. Existing saved reports update when rebuilt.
