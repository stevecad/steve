# Keyboard shortcuts

Open **Settings → Keyboard shortcuts**. Steve's existing bindings remain the default.

Choose Steve, Fusion, or SOLIDWORKS. Presets use supported Steve equivalents; they are not full emulations of another application. S opens Steve's command palette for both external presets. Fusion includes modeling, sketch tools, measure, appearance, visibility, rebuild and document navigation. SOLIDWORKS includes standard views, fit, rebuild, full screen, new document and document navigation. Unmapped Steve bindings remain unless claimed by the selected preset.

Search commands, click a binding and press a key combination. Conflicting assignments require an explicit Replace action. Clear removes the binding; Reset custom bindings restores the selected preset. Selecting another preset clears custom bindings. Preferences save locally and survive restart. Mouse style remains independently selectable under Navigation.

Escape, contextual Enter, text editing, chat submission and drawing-canvas gestures are not customized by this command binding page. Presets do not implement missing CAD commands. Menu and ribbon shortcut labels follow the selected command bindings.
